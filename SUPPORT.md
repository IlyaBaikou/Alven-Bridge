# Support boundary

Alven Bridge supports the published container, Compose file, protocol versions, and capability matrix.
It does not administer a household's router, NAS operating system, Ollama models, LM Studio models,
Docker host, or third-party backups.

Bridge never requires a support person to obtain remote shell access or household content. Diagnostics
must be content-redacted. If safe diagnosis is impossible, the supported recovery is credential
rotation, re-pairing, rollback, or a clean reinstall with the state volume preserved where appropriate.
